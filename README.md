DeepFake Detection for Evidence

A full-stack system that detects deepfake audio and video for use in legal and forensic environments.
It uses AI models, signal processing, and web technologies to classify whether media is Real or Fake with confidence scores.


🚀 Features

🎥 Video DeepFake Detection (CNN / EfficientNet-based models)

🔊 Audio Fake Detection (spectrogram + transformer-based models)

📊 Confidence Score Output

📁 Supports multiple file formats (MP4, WAV, MP3)

🔧 Backend built with Python (Flask/FastAPI)

🌐 Frontend built with React / Vite

🧪 Batch testing mode for datasets

⚠️ Evidence-oriented results for digital forensics
